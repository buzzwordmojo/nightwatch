# Marketing UI kit

A project landing page for the rebranded KnightWatcher. There is no marketing site in the source repo — every claim, sensor spec, and command on this page is lifted verbatim from `nightwatch/README.md`, `docs/SENSORS.md`, and `hardware/SHOPPING_LIST.md` rather than invented.

`LandingPage.jsx` — nav, hero with a live dashboard preview, three value props, the sensor table, a build/quick-start block, and a footer carrying the "not a medical device" notice.
