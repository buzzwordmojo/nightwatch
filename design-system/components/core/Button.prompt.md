The standard KnightWatcher action button — use for every clickable action; `outline` for secondary/back actions, `warning`/`danger` only for alert-resolution actions.

```jsx
<Button variant="default" size="lg">Get Started</Button>
<Button variant="outline" size="sm">Back</Button>
```

Variants: default (blue), outline, secondary, ghost, link, success, warning (black label on amber), danger, destructive. Sizes: default (40px), sm (36px), lg (44px), icon (40×40). Put lucide icons inline as children; the button gaps them at 8px.
